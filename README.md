# Progressive Web App

A modern Progressive Web App (PWA) built with HTML and JavaScript, designed to deliver a fast, reliable, and engaging user experience.

## Features

- ✨ **Progressive Enhancement** - Works for everyone, with enhanced experience for capable browsers
- 📱 **Mobile First** - Responsive design optimized for all devices
- ⚡ **Fast Performance** - Optimized loading and runtime performance
- 🔒 **Secure** - Served over HTTPS
- 📴 **Offline Support** - Works offline with service workers
- 💾 **Installable** - Can be installed as an app on home screen

## Technologies Used

- **HTML5** - Structure and semantic markup
- **JavaScript** - Interactivity and app logic
- **Service Workers** - Offline functionality and caching
- **Web App Manifest** - Installation and branding

## Getting Started

### Prerequisites
- A modern web browser
- A local web server (for local development)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Yolanda-loo/Progressive_web_App.github.io.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Progressive_web_App.github.io
   ```

3. Serve the files using a local server:
   ```bash
   python -m http.server 8000
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```
